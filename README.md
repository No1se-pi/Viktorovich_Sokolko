# Сайт адвоката Льва Викторовича Соколко

Статический одностраничный сайт без сборщика и внешних JavaScript-зависимостей.

Для локального просмотра откройте `index.html` или запустите любой статический сервер, например:

```powershell
npx serve .
```

## Перед публикацией

Необходимо получить и добавить:

- постоянный домен для canonical и sitemap.

На сайте используются подтверждённые данные: регистрационный номер 50/8307, стаж по юридической специальности с 2008 года, четыре направления практики, телефон и e-mail. Адреса и реквизиты сторонних организаций намеренно не публикуются.

Сайт остаётся статическим: формы сбора данных нет, для связи используются ссылки `tel:` и `mailto:`. Политика обработки персональных данных ведёт на опубликованный документ коллегии адвокатов «Династия».
