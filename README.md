# Сайт адвоката Льва Викторовича Соколко

Статический одностраничный сайт без сборщика и внешних JavaScript-зависимостей.

Для локального просмотра откройте `index.html` или запустите любой статический сервер, например:

```powershell
npx serve .
```

## Перед публикацией

Необходимо получить и добавить:

- электронную почту и адрес для встреч;
- регистрационные данные адвоката, регион или адвокатскую палату;
- точные направления юридической помощи;
- утверждённую политику обработки персональных данных;
- постоянный домен для canonical и sitemap.

На текущем этапе для связи используется только подтверждённый телефон. Форма обратной связи не добавлялась.
